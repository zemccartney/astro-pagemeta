M5

OG image generation

Post-v1

The original itch. A pluggable image-generator system hooking into pagemeta; seed prototype preserved in image-gen-wip/. Design starts only after v1 ships.

⚖️ Decision queue — settled 2026-07-03

All five decided by Zack (scratch/m1.md), matching the recommendations below. Implemented so far: 7-day release age + workspace deps scripts; Astro v5 dropped. Renovate, Socket, and OIDC publishing land in M2/M4. Measured floor: the package adds ~62 packages to a consumer's tree, essentially all from the wooorm/unified collective.

1 · Published deps: pins or ranges?

Rec: caret ranges. Exact pins block consumers' dedupe + patching; the lockfile already pins dev/CI.

2 · minimumReleaseAge: 3d → 7d?

Rec: 7 days. Best single defense against compromised releases; escape hatch exists.

3 · Renovate or manual cadence?

Rec: Renovate post-M2. Auto-merge dev patches after CI green; discipline is what the 3-month gap broke.

4 · Scanners?

Rec: Socket + pnpm audit. Behavioral analysis catches what CVE feeds can't; skip Snyk/Trivy for now.

5 · npm auth?

Rec: trusted publishing (OIDC). No long-lived token; provenance included.

6 · Drop hast-util-select?

Withdrawn 2026-07-03. rehype-meta depends on it anyway — zero packages saved. No decision needed.
